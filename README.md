# Swag Labs Automation Testing 🧪

This project contains automated UI test cases for the [Swag Labs](https://www.saucedemo.com/) web application. 
The tests are implemented using **Java**, **Selenium WebDriver**, **TestNG**, and follow the **Page Object Model (POM)** design pattern.

---

## 📌 Project Objectives

- Automate key user scenarios on Swag Labs.
- Apply POM for maintainable and scalable test code.
- Use TestNG for test organization and suite execution.

---

## 🚀 Technologies Used

- Java  
- Selenium WebDriver  
- TestNG  
- Maven  
- WebDriverManager  
- FirefoxDriver  
- IntelliJ IDEA

---


---

## ▶️ How to Run the Tests

1. **Clone the repository**
   ```bash
   git clone https://github.com/ManalKS5/Swag-Labs-Automation.git
   cd Swag-Labs-Automation


2. **Open the project in IntelliJ IDEA or any other Java IDE.**

3. **Run the test suite**

- Locate and run the testng.xml file.

- Or, right-click on any test class in tests and run it.
